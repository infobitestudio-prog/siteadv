# Sites para escritórios de advocacia: 30 modelos

Demonstração estática dos 30 modelos de site. A primeira página é a galeria numerada; cada modelo fica em `m/01/` a `m/30/`.

Todos os modelos usam o mesmo painel administrativo, as calculadoras jurídicas, a landing page, o perfil dos advogados com selo de inscrição verificada e o assistente de textos com IA. O formulário de contato e o painel funcionam apenas na versão hospedada com PHP.

Fotos: Unsplash (ver `assets/img/demo/CREDITOS.txt`). Escritório, nomes e números de OAB são fictícios. Fontes sob SIL Open Font License (`assets/fonts`).
